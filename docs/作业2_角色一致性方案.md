# 作业2 · 角色一致性方案与绘本排版

> 代码：`src/week2_illustration/`　｜　产物：`outputs/book/把光借给你.pdf`、`outputs/book/index.html`

---

## 一、问题到底是什么

文生图模型没有"记忆"。同一个 prompt 里的"七岁女孩"，第一次画出来是圆脸，
第二次可能是长脸；服装颜色、发饰、随身物品全都会漂移。
故事绘本最怕这个——读者一眼就能看出"这不是同一个人"，整本书的可信度就没了。

所以这个作业真正要解决的不是"画得好看"，而是**跨场景的身份稳定性**。

---

## 二、三种主流方案，我为什么选组合拳

| 方案 | 做法 | 成本 | 稳定性 | 我的判断 |
| --- | --- | --- | --- | --- |
| ① 详细外貌描述 + 固定 seed | 把外貌写死成一段文本，seed 固定 | 极低（每次 1 次调用） | 中：seed 只保证"同样输入同样输出"，换个场景描述就漂 | 必做，但不够 |
| ② 角色参考图 + IP-Adapter / img2img | 先出角色设定图，后续每张都以它为条件图 | 低（多一次编码） | 高：五官、发色、服装被参考图锁住 | **主力** |
| ③ LoRA 微调 | 用 20-50 张同角色图训一个小模型 | 高（训练 + 存储 + 调参） | 最高 | 8 个场景不值当，放弃 |

**结论：① + ② 组合。**
① 负责"文字层不漂"，② 负责"像素层不漂"，③ 留给以后角色要复用几十次的项目。

## 三、具体实现（三步）

### 第 1 步：把角色写成"不可变特征卡"

`src/week2_illustration/illustrator.py` 里的 `CHARACTER_SHEET` 是**唯一事实源**：

```python
CHARACTER_SHEET = {
    "小满": "七岁中国女孩小满，齐耳黑色短发，左侧别一枚红色小发卡，圆脸大眼，"
            "穿深蓝色带白色小星星图案的睡衣，赤脚，怀里抱一只掉了左耳的浅棕色旧兔子玩偶",
    "阿灯": "巴掌大的纸灯笼精灵阿灯，竹骨糊米白色宣纸，纸面有两处方形补丁，"
            "灯芯是一小团橘色火苗，火苗上有一双圆眼睛和一张笑嘴",
    "墨墨": "拳头大的灰黑色毛绒小云怪墨墨，边缘像棉花一样毛茸茸，"
            "两只圆圆的大白眼睛，着急时边缘会滴下小水珠",
}
```

为什么要写成"设定文本"而不是"每次自由发挥"？
因为自然语言描述是最便宜、最可 diff、最容易被 review 的"角色资产"。
它同时被三处消费：文生图 prompt、绘本角色介绍页、TTS 的角色音色描述。

### 第 2 步：prompt 拼装顺序固定

```python
def build_prompt(scene_desc, scene_visual, characters):
    head = "保持以下角色形象完全一致：" + "；".join(CHARACTER_SHEET[c] for c in characters)
    body = f"。场景：{scene_desc}。画面内容：{scene_visual}"
    return f"{head}{body}。{STYLE_SUFFIX}"
```

角色卡放在**最前面**——多数模型对 prompt 前段的注意力更高。
风格后缀 `STYLE_SUFFIX` 也全局唯一（"水彩与彩铅质感、米白纸纹、柔和描边"），
保证 8 张图放进同一本书里不违和。

### 第 3 步：以角色设定图作参考图做条件生成

先单独生成一张三分格设定图 `00_character_sheet.png`（三个角色并排、米白背景），
之后每个场景都以它为 `image1` + `input_fidelity=high` 生成。
这等价于 IP-Adapter 的思路：不训模型，只喂参考图。

设定图本身也是交付物——它被直接排进绘本第 2 页"认识一下他们"。

## 四、效果评估

### 4.1 逐维度人工核对（8 个场景）

| 场景 | 短发 | 红发卡 | 星星睡衣 | 兔子玩偶 | 纸灯笼（补丁+火苗眼） | 毛绒云怪 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 卧室 | ✓ | ✓ | ✓ | ✓ | —（未出场） | — |
| 2 阁楼 | ✓ | ✓ | ✓ | ✓（放在箱子上） | ✓ | — |
| 3 飞行 | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| 4 遇袭 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 5 低落 | ✓ | ✓ | ✓ | ✓ | ✓（光变弱） | — |
| 6 路灯 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓（流泪） |
| 7 赠灯 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 8 黎明 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

**8/8 场景主角形象一致**（发型、发饰、睡衣图案、兔子玩偶四项全部命中）。
`—` 表示该角色按剧本未出场。

### 4.2 两次失败与修正（真实记录）

| 失败 | 现象 | 原因 | 修正 |
| --- | --- | --- | --- |
| scene01 v1 | 床头柜上多了一只**带笑脸的灯笼**，但第 1 幕灯笼还在阁楼 | 参考图里三个角色并排，模型把"灯笼"当成了场景道具一起搬进来 | prompt 里加显式否定：**"画面中只出现小满和兔子玩偶，不要出现灯笼，不要出现云怪"** |
| scene06 v1 | 背景变成灰白渐晕，云怪蹲在灯笼上，没有街道和路灯 | 场景描述里"最后一盏路灯"是抽象表述，模型没抓到"环境" | 把环境写实：**"空无一人的街道、最后一盏路灯还亮着、暖黄灯光洒下一个小光圆、湿漉漉的石板路、远处建筑轮廓"** |

两张废弃图都留在 `outputs/images/scene01_v1_废弃.png`、`scene06_v1_废弃.png`，
作为"prompt 迭代前后对比"的证据，没有删。

**这两次失败给了一条可复用的经验：条件生成时，否定句和"环境锚点"比形容词更有效。**

### 4.3 一致性的量化口径

肉眼判断容易自我说服，所以我给了一个可执行的检查清单：

1. 遮住场景背景，只看角色剪影——能认出是同一角色吗？
2. 四个特征项（发型/发饰/服装/随身物）逐项打勾，少一项算不一致；
3. 把 8 张图缩成 200px 缩略图排成一行，看有没有"跳出来"的那一张。

第 3 条最有效——缩略图下细节全没了，只剩造型和配色，漂移会立刻暴露。

## 五、排版：为什么是 PDF + 网页两套

| 形态 | 用途 | 实现 |
| --- | --- | --- |
| PDF（A4 竖版，11 页） | 打印、交作业、给孩子翻 | reportlab，封面标题用 PIL 烘焙进图（避免"图一页、字一页"），正文楷体 15pt / 行距 29pt，页脚细线 + 页码 |
| 网页绘本 | 手机上翻、演示时全屏 | 单文件 HTML，点击左右半屏 / 方向键翻页，CSS `rotateY` 做翻页手感 |

两个细节：

- **图片压到 1400px 宽、JPEG q88**：不压的话 PDF 是 48 MB，压完 5.4 MB，
  A4 打印看不出一像素差别。这是"交付物要能发得出去"的基本要求。
- **正文首行缩进 2 字、行距 29pt**：儿童读物字要大、行要松，
  15pt/29pt 是给 6-8 岁孩子（和陪读的家长）留的呼吸空间。

## 六、复现

```bash
# 用已有图排版（秒级）
python scripts/run_week2.py

# 重新调文生图 API 生成全部配图（需要 IMAGE_API_KEY）
python scripts/run_week2.py --generate
```

生成新配图时，`illustrate_story()` 会自动：先出角色设定图 → 再逐场景条件生成 →
把每张图的 prompt、seed、涉及角色写进 `outputs/images/manifest.json`，
方便以后复现或排查"这张为什么画歪了"。
