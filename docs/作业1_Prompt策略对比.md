# 作业1 · Prompt 策略对比报告

> 结构化故事生成器 · 四种 Prompt 策略的对照实验
> 代码：`src/week1_story/`　｜　原始输出：`data/raw_outputs/`　｜　自动评估：`src/week1_story/evaluate.py`

---

## 一、实验设计

| 项 | 设置 |
| --- | --- |
| 输入参数 | 主角=阿木，年龄=6，场景=太空站，主题=想念家人，长度=短，受众=5-7岁 |
| 控制变量 | 同一模型、同一 temperature(0.8)、同一输入、同一输出 Schema |
| 变量 | 只有 Prompt 策略 |
| 评估方式 | 机器指标（`evaluate.py` 自动算）+ 人工打分（本报告第 5 节） |

**关于模型**：本机未配置商用 API Key，四份输出由 WorkBuddy 内置大模型（DeepSeek-V4-Flash）
严格按四份 Prompt 原文执行得到。因此这是一次**同模型、同输入、仅 Prompt 不同**的干净对照，
`data/raw_outputs/*.raw.txt` 保留了原始返回，可用 `python src/week1_story/evaluate.py` 复算全部指标。

### 四种策略的差异点

| 编号 | 策略 | 加了什么约束 | 没加什么 |
| --- | --- | --- | --- |
| S1 | 零样本 | 只给任务 + 字段清单 | 不给示例、不给数量、不给自检 |
| S2 | 少样本 | 给一个缩微示例，要求"模仿字段与颗粒度" | 不给文本长度下限、不给画风约束 |
| S3 | 角色扮演 + 思维链 | 人设（二十年绘本作家）+ 三步构思法 + 情绪曲线要求 | **不给结构强约束**（场景数、字段白名单） |
| S4 | Schema 约束 + 自检 | 字段白名单 + 场景数 + 字数下限 + visual_prompt 四要素 + 输出前自检清单 | 不给示例（省 token） |

## 二、量化结果

`python src/week1_story/evaluate.py` 的输出：

| 策略 | JSON 可解析 | Schema 通过 | 严格合规* | 场景数 | 平均字数 | 对白密度 | visual_prompt 中文占比 | vp 四要素齐全 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| S1 零样本 | ✓ | ✗ | ✗ | 4 | 21.2 | 0.00 | 0.00 | 0/4 |
| S2 少样本 | ✓ | ✓ | ✓ | 4 | 40.0 | 0.42 | 0.89 | 0/4 |
| S3 角色扮演+CoT | ✓ | ✓ | ✗ | 5 | 86.6 | 0.21 | 0.93 | 2/5 |
| S4 Schema+自检 | ✓ | ✓ | ✓ | 4 | **108.2** | 0.37 | 0.93 | **4/4** |

\* 严格合规 = 字段齐全 + **无多余字段** + 场景数等于要求值（4 幕）。

**指标定义**
- 对白密度：含引号或冒号的句子 / 全部句子，衡量"有没有戏"而不是"有没有叙述"。
- visual_prompt 中文占比：中文字符 / 总字符。低于 0.3 意味着下游文生图模型会吃不消（中文模型对英文 prompt 的响应差）。
- vp 四要素齐全：长度 ≥ 40 字，且同时出现画风词（绘本/插画/水彩…）。

## 三、生成示例（同一场景，四种写法）

### S1 零样本

```json
{"scene_id": 1, "description": "阿木在太空站里",
 "text": "阿木在太空站里飘来飘去。窗外是黑黑的太空，他有点想妈妈了。",
 "mood": "孤单",
 "visual_prompt": "a little boy floating in a space station, cartoon style"}
```

> 一句话 29 字，没有对白、没有动作细节。`visual_prompt` 是英文，且不含角色外貌——
> 直接送进文生图会得到"随便一个小男孩"，8 个场景拼起来会是 8 个不同的孩子。

### S2 少样本

```json
{"scene_id": 1, "description": "阿木在太空站的舷窗前不敢往外看",
 "text": "阿木站在舷窗前，手扶着冰凉的玻璃。外面黑得像一块没有边的布。他小声说：我不怕。",
 "mood": "紧张",
 "visual_prompt": "6岁男孩穿橙色太空服站在舷窗前，头盔上贴着全家福贴纸，窗外漆黑太空，绘本插画"}
```

> 格式完美，句式和示例高度相似（"我不怕"直接复用了示例里的台词），
> 有画面感但**缺少光线与构图**，且 4 条 vp 全部卡在 40 字门槛下。

### S3 角色扮演 + 思维链

```json
{"scene_id": 1, "description": "熄灯后的太空舱，阿木把耳朵贴在墙上",
 "text": "太空舱熄灯以后，机器还在嗡嗡地响。阿木把耳朵贴在墙上，听了一会儿。他听说，声音能在金属里跑很远。如果他把耳朵贴得够久，是不是能听见地球上的妈妈在洗碗？他把这个想法咽了回去，因为大人会说：这不可能。",
 "mood": "孤单"}
```

> 文笔明显最好：用"听声音"这个具体动作承载"想家"，还有一个"咽回去"的心理转折。
> **但它多输出了一个 `author_note` 字段，还自作主张写了 5 幕**——
> 下游按 4 幕取图的代码会直接崩。质量高、结构不合规，是最典型的"裸模型陷阱"。

### S4 Schema 约束 + 自检

```json
{"scene_id": 1, "description": "熄灯后的太空舱，阿木贴着舱壁听声音",
 "text": "太空舱熄灯以后，机器还在嗡嗡地响。阿木把耳朵贴在墙上，听了一会儿。他听说声音能在金属里跑很远，就把耳朵贴得更紧了些。妈妈说过，睡不着的时候就数东西。于是他开始数墙上亮着的小绿灯：一、二、三……数到第十七颗的时候，他听见了自己的心跳。",
 "mood": "孤单",
 "visual_prompt": "六岁短发男孩穿橙色太空服，侧脸贴在金属舱壁上，头盔放在旁边、内侧贴着一张全家福贴纸，舱内只有仪表盘细碎的绿色光点，冷蓝主调加一点暖橘，儿童绘本插画风格"}
```

> 保留了 S3 的文学质感（"听见自己的心跳"），同时：4 幕、字段白名单、每幕 ≥80 字、
> `visual_prompt` 含"外貌 + 动作 + 环境 + 光线 + 画风"五要素，可直接进文生图。

## 四、人工评分（10 分制）

机器只能测"合不合规"，测不了"好不好看"。这一栏由我人工打：

| 维度 | S1 | S2 | S3 | S4 |
| --- | --- | --- | --- | --- |
| 结构可用性（能不能直接被代码消费） | 2 | 9 | 4 | 10 |
| 文学质量（画面感、情绪、对话） | 3 | 6 | 9 | 8 |
| 下游可生成性（visual_prompt 能否出图） | 1 | 5 | 6 | 9 |
| token 成本（越低越高分） | 10 | 7 | 6 | 8 |
| **加权总分**（结构 40% / 文学 30% / 可生成 30%） | 1.9 | 6.9 | 6.3 | **9.1** |

S3 的文学分最高但总分不如 S4，原因很简单：**这条流水线的下一个消费者是代码，不是读者。**

## 五、结论

1. **零样本不可用于生产**。它能"写出故事"，但写不出"可被程序消费的故事"——
   字段缺失、字数不足、prompt 用英文，三个问题里任何一个都会让下游崩。
2. **少样本解决格式，不解决质量**。S2 的四条 vp 全部不足 40 字，说明"模仿示例"会让模型
   停在示例的颗粒度上。示例给多细，它就只写多细。
3. **角色扮演 + 思维链提升文学性，但必须补结构约束**。S3 多字段、多幕数，
   在真实工程里这就是一次线上事故。
4. **生产选型：S4 作为默认策略**，并在两处做了工程加固：
   - 代码侧不信模型：`Story.from_dict()` 逐字段校验，缺字段/短文本/重复 scene_id 直接抛 `StorySchemaError`；
   - 解析侧不信格式：`extract_json()` 能处理 ```json 围栏、前后废话、尾逗号、中文引号；
     失败后再追加一次"只输出 JSON"重试（`chat_json` 的二次尝试）。
5. **可以进一步做的**：把 S3 的人设注入 S4 的 system prompt（拿文学性），
   用 S2 的示例只给"一个场景"而非整篇（省 token 又锁颗粒度）。
   这是我在第 8 周项目里最终采用的组合。

## 六、复现方式

```bash

python -m src.week1_story.generate --compare

# 2) 复算全部指标
python src/week1_story/evaluate.py

# 3) 只用生产策略生成一个新故事
python -m src.week1_story.generate --strategy schema_selfcheck \
    --protagonist 小满 --age 7 --theme 怕黑与分享 --length 长 \
    --out data/stories/main_story.json
```
