## 一、音色映射表（角色 → 音色 → 参数）

| 角色 | 音色（Edge TTS） | 定位 | 基础语速 | 基础音高 | 选择理由 |
| --- | --- | --- | --- | --- | --- |
| 旁白 | `zh-CN-XiaoxiaoNeural` | 温柔女声 | −8% | +0Hz | 慢一点，给孩子留出看图的时间 |
| 小满 | `zh-CN-XiaoyiNeural` | 少女音 | −2% | +4Hz | 清亮、情绪起伏大，适合"嘴硬心软" |
| 阿灯 | `zh-CN-YunxiNeural` | 年轻男声 | +4% | +2Hz | 语速偏快，带笑意，符合"话多爱打嗝" |
| 墨墨 | `zh-CN-YunjianNeural` | 低沉男声 | −14% | −6Hz | 慢而低，一开口就"孤单" |

**四个角色的音高两两相差 ≥ 4Hz，语速相差 ≥ 6%**，
这是我能想到的最省事的"音色区分度"可量化标准——
闭着眼睛听，至少能分出"有人在说话"和"是谁在说话"两件事。

## 二、情感标注：不是形容词，是三轴参数

脚本里每句话都带一个情绪标签（`data/stories/script.json` 的 `emotion` 字段），
但它不会直接进 TTS——它先被映射成 **rate / pitch / volume** 三个可执行参数：

| 情绪 | rate | pitch | volume | 用在什么地方 |
| --- | --- | --- | --- | --- |
| 平静 | +0% | +0Hz | +0% | 叙述过渡 |
| 紧张 | +9% | +3Hz | +0% | 熄灯后听见"咔哒"声 |
| 低语 | −16% | −3Hz | −18% | "谁在那儿？" |
| 惊奇 | +6% | +7Hz | +4% | 灯笼睁开一只眼睛 |
| 兴奋 | +13% | +8Hz | +6% | "抓紧了！" |
| 温暖 | −7% | +1Hz | +0% | "黑是盖着被子的" |
| 温柔 | −11% | −1Hz | −3% | 天快亮的时候 |
| 低落 | −13% | −5Hz | −8% | 阿灯的光暗了一圈 |
| 心疼 | −11% | −2Hz | −4% | 发现墨墨在滴水 |
| 悲伤 | −15% | −7Hz | −10% | "我怕黑。" |
| 委屈 | −9% | −3Hz | −6% | "我吃掉它们，是想留一盏给自己。" |
| 嘴硬 | +11% | +5Hz | +5% | "我不是怕。" |
| 担心 | +5% | +2Hz | −2% | "我们回去吧。" |
| 惊讶 | +8% | +9Hz | +3% | "给我？" |
| 轻快 | +10% | +6Hz | +2% | "我明天再跟妈妈要一个。" |
| 释然 | −6% | +2Hz | +0% | 结尾那句 |

**最终参数 = 角色基础参数 + 情绪偏移**（`compose_params()` 做加法）。
所以"墨墨悲伤"是 −14%−15% = **−29% 语速、−13Hz 音高**，
而"小满嘴硬"是 −2%+11% = **+9% 语速、+9Hz 音高**——同一个"情绪"，在不同角色身上表现不同。

这就是我认为这个作业里最值钱的一点：
**情绪不是全局开关，是相对于角色基线的偏移量。**

## 三、工程实现

### 3.1 流程

```
script.json
   ├─ 逐行组装参数（角色基础 + 情绪偏移）
   ├─ 并发合成（信号量 4，单行失败重试 3 次，指数退避）
   ├─ mp3 → wav → 读 PCM 帧数 → 精确到毫秒的时长
   ├─ 按规则插入停顿 → 累加得到 timeline
   ├─ 拼接 PCM + 混入 BGM（旁白段落自动压低到 −6dB）
   └─ 导出 mp3 + timeline.json + 同步高亮网页
```

### 3.2 停顿规则（节奏感来自这里）

| 场景 | 停顿 | 理由 |
| --- | --- | --- |
| 同一情绪内换行 | 0.32s | 正常呼吸 |
| 情绪变化 | 0.55s | 给听众"情绪转弯"的时间 |
| 换说话人 | 0.22s | 对话要紧凑，不能像念稿 |
| 换场景 | 1.00s | 相当于翻页 |
| 开头 | 0.15s | 不要一上来就说话 |

### 3.3 为什么自己算时长，不用 ffprobe

`imageio-ffmpeg` 只带 ffmpeg 不带 ffprobe。所以流程是：
mp3 → 解码成 24kHz 单声道 wav → 用标准库 `wave` 读帧数 → `帧数 / 采样率`。
精度到毫秒，且零额外依赖。**字幕、高亮、视频剪辑三处共用这一份时间轴**，
所以三者天然对齐。

### 3.4 BGM：程序化生成，不用素材

`src/common/audio_utils.py` 里的 `make_bgm()` 用 numpy 合成：
C–Am–F–G 四和弦铺底 + 五声音阶八音盒旋律（随机游走 + 25% 概率留白）。
好处是版权干净、参数可复现、体积为 0。
同一个文件里的 `make_sfx()` 顺手生成了作业5 需要的 5 种音效。

## 四、同步高亮网页

`outputs/web/audiobook.html` 的三个细节：

1. **逐句高亮**：每句 `<p>` 带 `data-start/data-end`，`requestAnimationFrame` 里比对
   `audio.currentTime`，命中就加 `.on` 类并自动滚动到屏幕中间偏上。
2. **画面跟着场景走**：句子带 `data-scene`，场景一变就淡出淡入换插图——
   这样"听书"同时变成"看绘本"。
3. **点击跳转**：点任意一句直接 seek 到那句开头，方便反复听某一段。

## 五、验收对照

| 要求 | 达成情况 |
| --- | --- |
| 至少 3 个角色使用不同音色 | **4 个**（旁白/小满/阿灯/墨墨），音高两两相差 ≥4Hz |
| 情感与文本内容匹配 | 16 种情绪标签 → 三轴参数，逐句标注（54 句全部带标签） |
| 音频总时长 ≥ 3 分钟 | **4 分 52 秒** |
| 提供音色映射表 | 本文第 1、2 节，且在 `script.json` 里是数据而非文档 |
| 背景音效（加分） | 程序化八音盒 BGM，旁白段自动 ducking 到 −6dB |
| 同步高亮网页 | `outputs/web/audiobook.html`，逐句高亮 + 配图切换 + 点击跳转 |
