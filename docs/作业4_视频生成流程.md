# 作业4 · 故事短视频的自动剪辑

> 代码：`src/week4_video/make_video.py`　｜　产物：`outputs/video/把光借给你_故事短片.mp4`
> 规格：1920×1080 / 25fps / 4 分 53 秒 / H.264 + AAC / 硬字幕

---

## 一、路线选择：为什么是"剪辑式"

| 路线 | 做法 | 成本（本片 8 幕） | 可控性 | 结论 |
| --- | --- | --- | --- | --- |
| A 生成式 | 逐场景调可灵/Runway 生成 5-10s 片段 | 8 段 × ¥3-8 ≈ **¥30-60**，且要反复抽卡 | 低：角色、镜头、光线每次都不一样，和绘本图对不上 | 放弃 |
| B 剪辑式 | 已有绘本插图 + Ken Burns 运镜 + 原声 + 字幕 | **¥0**（纯本地 FFmpeg） | 高：每一帧都可复现，改一行参数重跑 | **采用** |

关键判断：**这个项目的"画面资产"已经在前一周做好了**（8 张角色一致的插图）。
再花钱生成一遍视频，不但贵，还会破坏刚建立起来的角色一致性。
所以正确的做法是"让静态图动起来"，而不是"重新画一遍"。

## 二、管线

```
timeline.json ─┬─ 按 scene 聚合出每幕的起止时间 ─┐
               │                                  ├─ ffmpeg zoompan → clip_00..07.mp4
               └─ 逐句字幕（含说话人/情绪）──┐    │
                                              │    ├─ concat → 无声视频
              audio.mp3 ──────────────────────┴────┼─ 混流 + ass 烧字幕 → 成片
```

三份输入，一份时间轴：**画面时长、字幕时间、音轨长度全部来自 `timeline.json`**，
所以不可能出现"字幕比画面慢半秒"这种问题。

## 三、Ken Burns：让静态图"呼吸"

每一幕都是一张静止的 1536×1024 插图，靠 `zoompan` 做缓慢推拉：

```python
# 偶数镜：从 1.0 缓慢推到 1.14
z = f"min(1+{0.14/frames}*on, 1.14)"
x = "iw/2-(iw/zoom/2)"      # 居中
y = "ih/2-(ih/zoom/2)"

# 奇数镜：从 1.14 缓慢拉回 1.0，并横向平移
z = f"max(1.14-{0.14/frames}*on, 1.0)"
x = f"(iw-iw/zoom)*on/{frames}"
y = "ih/2-(ih/zoom/2)"
```

三个细节：

1. **先放大到 1.34 倍再 zoompan**（`scale=2572:-2`），
   否则推近时源图分辨率不够，画面会糊。
2. **每幕方向交替**（推/拉、左移/居中），避免 8 幕看起来像同一个镜头重复 8 次。
3. **速度极慢**：整幕推完只放大 14%，5 分钟片子里几乎察觉不到"在动"，
   但一旦停下会立刻觉得"死"。这是纪录片常用的手法。

## 四、字幕：ASS 而不是 SRT

用 SRT 只能得到白字黑边，控制不了字体、位置、颜色、淡入淡出。所以生成 ASS：

```
Style: Sub,SimHei,46,&H00FFFFFF,...,Outline=2.4,Shadow=1.2,Alignment=2,MarginV=66
```

- **按说话人上色**：旁白近白 `&H00F2F2F2`、小满暖黄 `&H0090D8FF`、
  阿灯橙 `&H0068C8FF`、墨墨灰蓝 `&H00C0B0A8`。听不出是谁的时候，颜色能帮忙。
- **淡入淡出 140ms**：硬切会"跳"，140ms 刚好够眼睛跟上。
- **断行按标点，不按字数**。第一版是每 20 字硬切，出现了
  「……窗帘被风吹得鼓 / 起来，又瘪下去。」这种把词劈开的断法。
  改成：两行以内时，在所有标点里挑一个最接近句子中点的位置断行；
  超过两行才退回贪心填充。
- **片头/片尾单独样式**：标题 96px 楷体居中，寓意 54px，各自带 600-700ms 淡入。

## 六、踩过的坑

| 坑 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| concat 找不到 list.txt | `Error opening input file list.txt` | 片段在 `_clips/`，ffmpeg 的 `cwd` 却设成了 `video/` | 统一 `cwd` 到片段目录，ASS 也一起放进去 |
| Windows 中文路径 | concat 列表里的绝对路径带中文会转义失败 | concat demuxer 对非 ASCII 路径敏感 | 列表里只写**相对文件名**，靠 `cwd` 定位 |
| 字幕字体 | 中文全变方块 | libass 找不到 SimHei | 样式里显式写 `SimHei`，系统字体目录已存在 |
| 首帧黑屏 | 成片开头 0.2s 黑 | `-shortest` 与音频起始时间对齐问题 | 音频开头留 0.15s 静音，且 `-movflags +faststart` |
