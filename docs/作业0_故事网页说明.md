> 文件：`src/week0_web/index.html`（单文件，双击即开，无需服务器）

## 一、做了什么

一个"故事小屋"：填三个字段（主角名字 / 年龄 / 最喜欢的事），选一个世界，
点「开始讲故事」，就得到一本 5 页的专属绘本。

**四个世界**（满足"至少 3 种主题切换"）：

| 世界 | 故事内核 | 配色 |
| --- | --- | --- |
| 森林冒险 | 小鹿的铃铛丢了声音，只有听见真心喜欢的事才会响 | 暖绿 |
| 太空旅行 | 火箭贴纸半夜变成真的，飞到太空遇见一颗想听故事的星星 | 深蓝 |
| 海底世界 | 珊瑚灯全灭了，因为鱼们很久没有笑过 | 青蓝 |
| 夜晚城市 | 阁楼的旧纸灯笼叫阿灯，黑不是空的，黑是盖着被子的 | 墨蓝 |

## 二、交互设计上的几个决定

**1. 不让人填空，让人选。**
"故事主题"做成四张带插画的卡片而不是下拉框——孩子（和替孩子操作的家长）看图就能选，
不需要先理解"主题"这个词是什么意思。

**2. 生成是即时的，不是"等待中"。**
所有故事文案都在前端用模板 + 变量替换拼出来（`{name}/{age}/{like}`），
没有网络请求，点完立刻出结果。这一版刻意不接大模型——
第 2 周开始才把"生成"交给 API，第 1 周先把"体验"做对。

**3. 插画用内联 SVG，不用图片文件。**
四个世界各一套图层：森林是树干 + 树冠 + 双层山丘，太空是星点 + 行星 + 小飞船，
海底是水纹 + 珊瑚 + 小丑鱼，城市是楼群 + 亮窗 + 会发光的小灯笼。
好处是整个页面就一个 HTML 文件，发给谁都能直接打开，不会出现"图片裂了"。

**4. 阅读页是"书"，不是"文章"。**
左边画面、右边文字，底部圆点指示进度，翻页有轻微位移和淡入。
键盘 ← → 也能翻。最后一页出现"再讲一个 / 打印这一本"。

## 三、验收对照

| 要求 | 达成 |
| --- | --- |
| 输入：主角名字、年龄、兴趣、故事主题 | 三个输入框 + 四张主题卡 |
| 输出：可交互的故事展示页（含文本、样式） | 5 页绘本式阅读页，翻页/键盘/圆点进度 |
| 至少 3 种故事主题切换 | **4 种**，各自独立的文案与配色 |
| 页面美观、交互友好 | 米白纸质感、楷体、卡片式布局、悬停微动效 |
| 提交代码仓库 + 演示视频 | 代码在 `src/week0_web/`；演示见第 8 周录屏 |

## 四、怎么跑

直接双击 `src/week0_web/index.html`。
想直接看阅读页，地址后面加 `#demo`（这个分支是我用无头浏览器截图时加的）。
